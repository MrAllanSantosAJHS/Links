About Hyperlinks

A hyperlink (or link) is a clickable text, image, or element that takes a user to another location.

In HTML, links are created with the <a> (anchor) element. The href attribute tells the browser where the link should go.

<a href="https://www.w3schools.com/">Visit W3Schools</a>

Common types of hyperlinks

External link

Goes to another website.

href="https://example.com"

Internal page link

Goes to another page in this website.

href="contact.html"

Email link

Opens the visitor's default email app.

href="mailto:hello@example.com"

Image link

Makes an image clickable by placing it inside an anchor.

<a><img></a>

What does the title attribute do?

Move your pointer over this example and pause for a moment:

Hover over me

The title attribute provides advisory information. Many browsers display its value as a small tooltip when the pointer hovers over the element.

Remember: href tells the browser the destination. title gives extra information about the link.
