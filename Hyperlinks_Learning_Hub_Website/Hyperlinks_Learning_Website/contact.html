The four target attribute values

The target attribute tells the browser where to open the linked document.

1. _self

Opens the linked page in the same browsing context. This is the default behavior.

Try target="_self"

This tab will navigate to W3Schools.

2. _blank

Opens the linked page in a new tab or window.

Try target="_blank"

Your current page should remain open.

3. _parent

Opens the linked page in the parent browsing context (the frame containing the current page).

Try target="_parent"

When this page is not inside a frame, the parent is effectively this tab.

4. _top

Opens the linked page in the full, top-level browsing context, replacing any frames.

Try target="_top"

When this page is not inside a frame, it behaves like same-tab navigation.

Important classroom note: This website is not embedded inside frames. Therefore, _parent and _top may look the same as _self when you click them here. Their difference becomes visible when a page is inside nested frames or iframes.
