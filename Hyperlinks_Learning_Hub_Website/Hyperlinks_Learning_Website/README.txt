HYPERLINKS LEARNING HUB — WEBSITE FILES

Files:
- index.html   : Home page
- about.html   : About Us page (hyperlink concepts)
- contact.html : Contact Us page (mailto and target demonstrations)
- assets/style.css : Shared styles
- assets/eagle.svg : Original stylized eagle illustration

HOW TO VIEW:
1. Extract this ZIP file.
2. Keep the folder structure exactly as it is.
3. Double-click index.html to open the Home page in a browser.
4. Use the navigation menu to visit About Us and Contact Us.

DEMONSTRATIONS:
- Internal page links between the three HTML files
- External W3Schools link
- Clickable eagle image linking to https://www.ateneo.edu/
- mailto: email link (sample address: hello@example.com)
- target values: _self, _blank, _parent, _top
- title attribute tooltip examples

NOTE ABOUT TARGET:
This site is not embedded in frames. Therefore _parent and _top can appear to behave like _self.
Their different behavior is relevant when the page is opened within frames/iframes.

TEACHER TIP:
Replace hello@example.com in contact.html with the email address you want students to use.
